Публикация по решению автора.

Pearce Publisher помогает работать с подготовленными изображениями и видео в отдельных авторских проектах. Аккаунты, учётные данные, очереди и состояние операций каждого автора разделены.

Pinterest: доступ к API получен. Аккаунт владельца проверен через API. Эта страница описывает назначение приложения и подготовленной интеграции; подключение не включает автоматическую публикацию материалов.

Как запланирована работа с Pinterest

  1. Владелец подключает свой бизнес-аккаунт через официальный OAuth Pinterest. Приложение не запрашивает пароль или session cookies Pinterest.
  2. Автор выбирает подготовленный материал, название, описание, ссылку и одну из доступных досок.
  3. Загрузка или создание пина выполняются после явного решения владельца о конкретном материале. Само подключение аккаунта ничего не публикует.
  4. Инструмент проверяет результат согласованной операции. Доступы разных авторских проектов не смешиваются.

Разрешения и данные

Для начального подключения предусмотрены user_accounts:read, boards:read, pins:read и pins:write. Фактически доступные права определяются Pinterest и согласием владельца аккаунта. Создание досок не требуется для первоначального подключения.

Информационный сайт не принимает OAuth-токены, пароли и файлы авторов. Подробнее о данных, отключении доступа и обращениях — в политике конфиденциальности.

YouTube

Для собственного канала автора используется YouTube Data API v3. Приложение проверяет идентификатор подключённого канала и может загружать выбранное владельцем видео, включая Shorts. Доступ запрашивается через официальный Google OAuth: youtube.upload — для загрузки видео, youtube.readonly — для проверки своего канала и результатов операций. Само подключение ничего не публикует.

OAuth-токены хранятся локально в macOS Keychain и не поступают на этот сайт. Данные Google используются для функций подключения и согласованной публикации; подробнее — в политике конфиденциальности.

For Pinterest reviewers

Pearce Publisher is a local publishing tool for author projects. The prepared integration is intended to read the authorized Pinterest business account and its boards, and create selected image or video Pins only with the account owner's explicit approval. Pinterest API access is available for the authorized owner account; publication is separately approved. The app does not collect Pinterest passwords or session cookies.
